# توثيق المؤثرات الإضافية

الملفات التالية مضمّنة في هذا المشروع بصيغة OGG:

| الملف | الاستخدام داخل اللعبة | المصدر | الترخيص |
|---|---|---|---|
| `purchase_success_cc0.ogg` | تأكيد شراء سيارة أو أداة أو وقود | WobbleBoxx Workshop — [Level Up, Power Up, Coin Get (13 Sounds)](https://opengameart.org/content/level-up-power-up-coin-get-13-sounds) | CC0 1.0 / ملكية عامة |
| `wheel_spin_cc0.ogg` | بداية تدوير عجلة الحظ | المصدر نفسه | CC0 1.0 / ملكية عامة |
| `wheel_reward_cc0.ogg` | إعلان نتيجة عجلة الحظ | المصدر نفسه | CC0 1.0 / ملكية عامة |

تم تحويل الملفات إلى OGG أحادي القناة ومعدل 44.1 كيلوهرتز من أجل التوافق مع طبقة صوت Android المستخدمة في المشروع.


## مؤثرات إدارة الغرف والإشعارات

الملفات التالية مستخرجة من حزمة **Interface Sounds** للمؤلف [Kenney](https://opengameart.org/content/interface-sounds)، المرخصة بموجب [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). الحزمة تقدم 100 ملف OGG منفصلًا بمستوى صوت موحّد.

| الملف في المشروع | الاستخدام |
|---|---|
| `room_player_join_cc0.ogg` | انضمام لاعب إلى الغرفة |
| `room_player_leave_cc0.ogg` | مغادرة لاعب للغرفة |
| `room_kick_cc0.ogg` | إخراج لاعب |
| `room_ban_cc0.ogg` | حظر لاعب |
| `invite_received_cc0.ogg` | وصول دعوة لعب |
| `message_send_cc0.ogg` | إرسال رسالة |
| `message_receive_cc0.ogg` | وصول رسالة خاصة أو رسالة غرفة |
| `robot_add_cc0.ogg` | إضافة روبوت إلى المباراة |
| `exit_confirm_cc0.ogg` | طلب تأكيد الخروج |
| `wheel_spin_long_cc0.ogg` | دوران عجلة الحظ لمدة تقارب 5.3 ثانية؛ أُنشئ من تكرار نغمة CC0 من الحزمة مع تلاشي نهائي |

المصدر المباشر للحزمة: <https://opengameart.org/sites/default/files/kenney_interfaceSounds.zip>.
